Instagram auto reply tool

## Description
This project is built using Vite and TypeScript. It is designed to run as a frontend web application.

## Prerequisites
Ensure you have the following installed before running the project:
- [Node.js](https://nodejs.org/) (Latest LTS version recommended)
- [npm](https://www.npmjs.com/) (Comes with Node.js)

## Installation
1. Clone the repository:
   ```bash
   git clone <repository_url>
   ```
2. Navigate to the project directory:
   ```bash
   cd project
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Running the Project
To start the development server, run:
```bash
npm run dev
```
This will start the Vite development server and provide a local URL where you can preview the application.

## Environment Variables
The project includes an `.env` file. Ensure all necessary API keys and environment variables are set correctly.

## Troubleshooting
If you encounter dependency issues, try:
```bash
npm install --force
```
or
```bash
npm install --legacy-peer-deps
```

## Build for Production
To build the project for production, run:
```bash
npm run build
```
This will generate optimized static files in the `dist` folder.
